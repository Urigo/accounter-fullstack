The Manual Automations screen shows the Deel pull as its fourth step. A "Deel documents pulled"
card lists each charge that got Deel invoices: a link to the charge, its date and amount, how many
invoices it got, and whether the run created it or updated an existing one. When Deel isn't
connected, the card says so and links to the Admin Config tab. The run summary also counts the
pulled Deel charges, except for a business without Deel.
