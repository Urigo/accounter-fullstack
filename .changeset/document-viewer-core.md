Document previews open in a new, wider document viewer. The preview drawer now takes half the
screen (the full width on phones) and opens at Fit width, so an invoice is readable without the
magnifier. The viewer adds Fit page / Fit width / 100% modes, +/− and typed zoom, Ctrl/⌘ + wheel
and trackpad pinch zoom around the cursor, drag to pan, double-click to toggle 200%, and loading,
error and "no preview" states with an Open original link. The magnifier is now an opt-in toggle
with a single S/M/L size control. Links to a document's image or file open only for http(s) URLs.
