Add comment threads to the dynamic report. Any report row can carry a discussion, opened from a
comments column next to the approval status, where branches also flag open threads below them; a
**Discussions · N open** toolbar button lists every thread as Open, Resolved or Not in report and
reveals the row it belongs to. Threads can be resolved and reopened, and authors can edit or delete
their own messages. Posting takes effect immediately, outside Save and on locked templates, and a
template's threads are shared across periods, with a chip on messages written for another period or
owner.
