# israeli-vat-scraper

# Pre execution:

- Pass the credentials to the scraper function, or set them as environment variables: copy
  [`.env.template`](./.env.template) to `.env` and fill in `VAT_NUM`, `USER_CODE` and `USER_PASS`.
