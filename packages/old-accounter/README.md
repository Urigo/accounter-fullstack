# old-accounter

> ⚠️ **Retired.** This is the original, pre-monorepo Accounter implementation. It is excluded from
> the Yarn workspaces (see the `!packages/old-accounter` entry in the root `package.json`), from
> `tsconfig.json`, from ESLint and from Prettier, so it is never installed, built, linted or
> formatted. It receives no dependency upgrades and is not deployed. Nothing in the repo imports it.
> It is kept purely as a historical reference — use `packages/server` and `packages/client` instead.

Its dependencies are not installed, so the code here will not run as-is. To revive anything from it,
copy the relevant source into a live package rather than re-enabling this one.
