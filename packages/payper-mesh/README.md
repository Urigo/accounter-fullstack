# payper-mesh

> ⚠️ **Deprecated.** Nothing in the monorepo uses this package and it is no longer maintained. It is
> excluded from the Yarn workspaces (see the `!packages/payper-mesh` entry in the root `package.json`),
> from `tsconfig.json`, from ESLint and from Prettier, so its dependencies — including GraphQL Mesh
> v0 — are its own rather than the monorepo's. It receives no dependency upgrades and is no longer
> released; the last published version is 0.2.13.
>
> To build it anyway, treat this directory as its own Yarn project:
> `touch yarn.lock && yarn install && yarn build` (the lockfile and Yarn state are git-ignored).
